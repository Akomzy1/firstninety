Spec notes

  • Sidebar: 240px, --paper background, 1px right border in --paper-3. Internal padding 24px top / 16px sides.
  • Active row: --ink text on a --paper-3 fill at 6px radius. No coral accent — the active state is a held breath, not a shout.
  • Inactive rows: --mute text. Hover lifts to --ink on a half-opacity fill.
  • Situation Room dot: 6px --accent circle, right-aligned. The only place coral is permitted in chrome.
  • "What I know about you": sits below the divider with a small Fraunces italic gloss — read the margins. Editorial, not decorative.
  • User menu: opens upward, 8px radius, ink-on-paper, soft shadow. Account / Billing / Memory & privacy / Sign out.

Spec notes

  • Top header: 56px, wordmark left, monogram right. No hamburger — the bottom nav is the navigation.
  • Bottom nav: 64px tall, --paper background, 1px top border in --paper-3. Five tabs, equal width.
  • Active tab: ink icon with a 4px indicator dot above it. Inactive tabs are --mute icon-only.
  • Situation Room dot: 5px --accent circle offset top-right of the icon, present even when the tab is inactive.
  • "More" drawer: slides from the right, sits above content but below the bottom nav so navigation stays reachable. Holds Coach, Playbook, the editorial "What I know about you" link, and the user menu.
