Wordmark

First·90 — the wordmark recut.

Fraunces at optical size 144. First in italic 400, an accent‑orange interpunct (--accent #D9532C, 0.34em × 0.34em, baseline‑raised 0.18em), then the upright numerals 90 at weight 600. The numeral does the work the word was hiding. The dot becomes the hallmark. Wordmark colour is --ink on light surfaces, --paper on dark.

Type scale

Two faces, used with restraint.

Fraunces for weight (display, headings, the wordmark). Inter for everything else. Sizes shown at desktop. Mobile drops one step per level. Headings balance to avoid orphan words.

Buttons

Three variants. Never pill-shaped.

Primary is the one main action per screen. Secondary supports it. Ghost is for tertiary actions. Corner radius is 0–4px. No shadow. Hover at 80ms.

Cards

Default. And one elevation, used sparingly.

32px internal padding. 8px corner radius — never higher. Default cards carry a 1px --paper-3 border. Elevated cards add one soft shadow, 0 1px 2px rgba(14,17,22,0.04). That’s it.

Two letters in Fraunces. No stock avatars.

Focus & accessibility

Visible focus. Honoured motion preferences.

A 2px --ink outline at 2px offset on every interactive element. Touch targets no smaller than 44×44. Non-essential motion respects prefers-reduced-motion. WCAG AAA on body text where feasible, AA minimum.

Focus ring
2px solid --ink, 2px offset. Never removed; same on hover.
Keyboard nav
Tab Enter Esc
Every surface is fully navigable without a pointer. Every icon-only control has an sr-only label.
