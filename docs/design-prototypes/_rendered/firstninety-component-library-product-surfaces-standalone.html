06 Status badges

Icon and text. Never colour alone.

Cross-product · status surfaces
Green flag Yellow flag Red flag In progress Completed Locked

Each badge: 8px / 14px padding · 4px radius · Inter 500 · 13px · icon at 1.5px stroke · colour-blind safe.

Used on scenario debriefs (flags), mission cards (in progress / completed / locked), and anywhere status is communicated. Strict rule: the word carries the meaning; colour reinforces.
